# DPOS350P-wav-tools

Decoder, viewer and measurements for the waveform files saved by the **FNIRSI DPOS350P**
oscilloscope, plus notes on two firmware issues found while decoding them.

Everything refers to the **2025-06-19 firmware** and was checked against 26 captures from a real unit.

## Examples

Interactive reports generated by `dpos350p_wav.py --plot --html` from two real captures. Each one has
the waveform with t = 0 at the trigger point and the trigger level, the FFT, the measurement table and
the screen thumbnail stored in the file.

| View online | Capture |
|---|---|
| [**16 – single channel, 440 Hz**](https://lrba86.github.io/DPOS350P-wav-tools/examples/16_single_channel_440Hz.html) | CH2 only, 200 mV/div, 5 ms/div, Single trigger at 0 V. Audio signal with a 440.1 Hz fundamental (FFT) |
| [**1 – two channels, pulses**](https://lrba86.github.io/DPOS350P-wav-tools/examples/1_two_channels_pulses.html) | CH1 10 V/div + CH2 20 V/div (x10 probes), 500 ms/div, Auto. Pulse train at 31.9 Hz; the 4-phase interleave offset is corrected before measuring ([details](docs/adc_interleave_offset.md)) |

The links open the interactive reports through GitHub Pages (zoom, pan, hover values). The source
files are in [`examples/`](examples/). The plotting library is loaded from `cdn.plot.ly`, so an internet
connection is needed.

## Quick start

```
cd tools/wav
pip install -r requirements.txt
python dpos350p_wav.py 1.wav --plot --html   # writes 1_onda.html
python -m pytest -q
```

See [`tools/wav/README.md`](tools/wav/README.md) for all options.

## Notes

- No FNIRSI binaries and no captures are included. The tests that need real files are skipped unless
  a folder `tools/wav/Ondas/` with `.wav` captures exists.
- These tools only read files. They do not modify the instrument.
- Analysis was done with the help of an AI assistant (Claude, by Anthropic). The results were
  reviewed and checked on real device files.
